# Channel TWRP / DroidSpaces

Recovery work for the Motorola Moto G7 Play (`channel`).

The current user-facing TWRP build is available from the `main` branch through:

**Build Channel TWRP 3.5.2**

That workflow builds the current DroidSpaces recovery with recovery Wi-Fi and hotspot support.

For normal use, run the workflow from the **Actions** tab and download the generated image artifact.

The validated target is the Motorola Moto G7 Play (`channel`, SDM632).
