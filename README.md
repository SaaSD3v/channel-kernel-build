# Channel Kernel Build

Automated kernel builds for Moto G7 Play (channel/SDM632) with ReSukiSU support.

## Supported Branches

| Branch | Kernel Version |
|--------|---------------|
| lineage-17.1 | 4.9.206 |
| lineage-18.1 | 4.9.206 |
| lineage-22.2 | 4.9.337 |

## Usage

Go to Actions tab and dispatch the workflow for your desired branch.
